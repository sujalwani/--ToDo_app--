
# 📝 Todo App

A modern and responsive Todo Application built using **HTML, CSS, and JavaScript**. This app helps users manage daily tasks efficiently with features such as task creation, completion tracking, filtering, deletion, and local storage support.

---

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete individual tasks
* 🔍 Filter tasks:

  * All Tasks
  * Active Tasks
  * Completed Tasks
* 🧹 Clear all completed tasks
* 💾 Save tasks using Local Storage
* 📱 Fully Responsive Design
* 📅 Displays current date
* 🎨 Clean and modern UI

---

## ⚙️ How It Works

### Add Task

Enter a task in the input field and click the "+" button or press Enter.

### Complete Task

Click the checkbox beside a task to mark it as completed.

### Delete Task

Click the delete icon to remove a task.

### Filter Tasks

Use the filter options to view:

* All Tasks
* Active Tasks
* Completed Tasks

### Clear Completed

Remove all completed tasks with one click.

### Local Storage

Tasks are automatically saved in the browser and remain available after refreshing the page.
